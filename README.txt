GEG Building to Road Slope - web app for iPhone, iPad and Android
Developed by Eng. Saman Abdulazeez

UPLOAD TO NETLIFY (on a computer, using Chrome or Edge)
- Update your existing link: open your site in Netlify > Deploys tab >
  drag THIS FOLDER (the one that contains index.html) into the drop area.
- Brand new link: go to https://app.netlify.com/drop and drag THIS FOLDER.

INSTALL ON A PHONE
- iPhone/iPad: open the link in Safari > Share > Add to Home Screen.
- Android: open the link in Chrome > menu (three dots) > Add to Home screen.
Open it once with internet; after that it works offline.

UPDATING LATER
Change VERSION at the top of sw.js (e.g. geg-slope-v4) before uploading,
so phones pick up the new version.
